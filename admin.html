Como usar

  1. Arraste o modelo 3D (.glb) e os PDFs das pranchas para as áreas abaixo (ou clique para escolher).
  2. Dê um título para cada prancha (ele aparece como aba no site), reordene com ↑ ↓ ou remova com ✕.
  3. Clique em Baixar dados.js e substitua o arquivo dados.js na pasta do site.
  4. Atualize a página do site (F5) para ver as mudanças.
