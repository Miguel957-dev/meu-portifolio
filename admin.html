Como usar

  1. Arraste as imagens para a área de cada projeto (ou clique para escolher).
  2. Escreva uma legenda, reordene com ↑ ↓ ou remova com ✕.
  3. Clique em Baixar dados.js e substitua o arquivo dados.js na pasta do site.
  4. Atualize a página do site (F5) para ver as fotos.
